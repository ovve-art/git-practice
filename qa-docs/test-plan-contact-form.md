# Test plan: Contact form (US-21), release 1.5.0

| Раздел | Содержание |
|---|---|
| Цель | Проверить корректность отправки формы обратной связи, валидации полей и сохранения сообщений. Подтвердить исправление BUG-5. |
| Объём: входит | Поля формы, обязательность, валидация Subject (4, 5, 20, 100, 101 символ), успешная отправка, POST /api/message, появление сообщения в Admin |
| Объём: не входит | Бронирование номеров, управление Rooms и email-уведомления: не относятся к US-21. |
| Подход | UI-тесты, API-проверки в Postman, позитивные и негативные сценарии, граничные значения, SQL-проверка сохранения (при наличии доступа), регрессия и ретест BUG-5. |
| Окружение | Стенд test, сборка 1.5.0, Chrome 130 |
| Тестовые данные | Валидные и невалидные значения полей, Subject длиной 4/5/20/100/101 символ. Уникальные темы с ID прогона и временной меткой, с сохранением точной длины для граничных проверок. |
| Критерии входа | Сборка 1.5.0 развёрнута, US-21 и ожидаемые результаты доступны, BUG-5 передан в Ready for QA. Есть доступ к форме, API и Admin → Messages. |
| Критерии выхода | Все запланированные кейсы выполнены, BUG-5 успешно прошёл ретест, нет открытых Critical/Blocker дефектов. |
| Риски | 1. BUG-5 не исправлен → повторный баг-репорт/возврат в разработку. 2. Нет доступа к Admin/БД → запросить заранее. |
| Результаты (deliverables) | Тест-кейсы и тест-ран в TestRail, баг-репорты, результаты ретеста BUG-5, итоговый QA-отчёт с рекомендацией по релизу. |
